Политика конфиденциальности приложения «Кешбек банковских карт»

Дата последнего обновления: 4 ноября 2026 года

Приложение «Кешбек банковских карт» (далее — Приложение) предназначено для личного учёта категорий кешбэка банковских карт и поиска наилучшего кешбэка среди банков, данные о которых добавил пользователь. Настоящая политика объясняет, какие данные обрабатываются, зачем и как ими управлять.

1. Какие данные обрабатываются

Учётные данные - Имя пользователя (логин) и хеш пароля — для входа в Приложение. Пароль хранится только в виде необратимого хеша (PBKDF2-SHA256).

Данные кешбэка, добавленные пользователем - Названия банков, категории и проценты кешбэка, название карты. - Изображения скриншотов банковских приложений, которые пользователь загружает для автоматического распознавания.

Технические данные - Необязательный личный API-ключ Google AI Studio, который пользователь указывает в настройках. Хранится только на устройстве пользователя и передаётся на сервер только вместе с запросом распознавания скриншота.

Приложение не собирает: контакты, геолокацию, историю покупок, номера карт, номера счетов и другие платёжные данные.

2. Как обрабатываются данные

  • Данные хранятся на сервере разработчика в базе данных PostgreSQL.
  • Скриншоты распознаются сервисом Google Gemini (Google AI Studio): изображение передаётся в API Google. Порядок обработки изображений регулируется условиями Google: https://policies.google.com/privacy
  • Распознанный результат сохраняется в базе данных; загруженный скриншот может сохраняться на сервере в уменьшенном виде как образец банка для будущего автоматического определения банка.
  • Пользователь видит данные членов семьи, привязанных к его семейной группе на сервере (для публичных пользователей по умолчанию данные видны только самому пользователю).

3. Передача данных третьим лицам

Данные не продаются и не передаются третьим лицам, за исключением передачи изображений в Google (Gemini API) для распознавания — только по явному действию пользователя (загрузка скриншота).

4. Срок хранения и удаление

  • Данные хранятся до удаления пользователем.
  • Удалить аккаунт и все связанные данные (логин, банки, категории, скриншоты-образцы, привязанные к пользователю) можно непосредственно в Приложении: Настройки → Удалить аккаунт и мои данные.
  • Удаление вступает в силу немедленно и необратимо.
  • Запрос на удаление также можно направить по электронной почте: unlying.debia@gmail.com

5. Доступ к данным

Доступ к данным пользователя имеет только сам пользователь (и члены его семейной группы — к данным друг друга). Разработчик не использует данные пользователей в аналитических или рекламных целях.

6. Дети

Приложение не предназначено для лиц младше 13 лет и не собирает их данные.

Обновления политики публикуются на этой странице. Существенные изменения дополняются уведомлением внутри Приложения.
